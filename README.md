# 今日待办

面向大学生的碎片事务提醒工具 —— **打开就看清今天要做什么**。

## 为什么做这个

大学里的琐事都是小事，但不做就会变成麻烦：水卡不充值会停水，衣服不洗会发霉，作业不看截止日期会错过。

这些事的共同点：**单件事成本极低（一两分钟就做完），但遗忘的代价很高。**

问题不是「没有地方记」，而是「记了之后没有一个恰当的时机被看见」。这个工具只解决这一句话。

所以它不做成功能更多的待办工具，而是做成**信息层级更清楚的**待办工具。

## 怎么运行

纯静态网页，不需要安装任何依赖，只要本机有 Python 即可。

### Windows

在项目目录下打开终端（命令提示符 / PowerShell），执行：

```
py -m http.server 8000
```

### macOS / Linux

```
python3 -m http.server 8000
```

然后浏览器打开 **http://localhost:8000**

停止服务：在终端里按 `Ctrl + C`

### 注意事项

- 命令执行后终端会「卡住」不动，这是正常的 —— 它正在提供服务。**别关那个窗口**，关了页面就打不开了。
- 改完代码不用重启服务，浏览器按 `F5` 刷新即可；如果样式没更新，用 `Ctrl + F5` 强制刷新。
- 提示端口被占用时，把 `8000` 换成别的数字（如 `8001`），访问地址也跟着改。
- **不要直接双击 `index.html` 打开。** 那样地址栏是 `file://`，IndexedDB 的行为在各浏览器不一致，后续要加的 Service Worker（离线与推送）在 `file://` 下会被浏览器直接禁止。开发时一律走 `http://`。

### 在手机上打开

手机和电脑连同一个 Wi-Fi，用电脑的局域网 IP 访问（例如 `http://192.168.1.5:8000`）。

- 查本机 IP：Windows 执行 `ipconfig`，看「IPv4 地址」
- 服务需要监听所有网卡：`py -m http.server 8000 --bind 0.0.0.0`
- 如果手机连不上，先检查 Windows 防火墙是否放行了 Python

## 数据存在哪

事项数据存在**浏览器内置的 IndexedDB** 里，不上传任何服务器，也没有账号体系。

- 手机和电脑**各存各的，不互通** —— 这是本期的明确决定，不是遗漏（见 `PRD.md` 6.2）
- 清理浏览器数据会连事项一起清掉
